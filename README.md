# probesemver

Probe HTML/Markdown semver fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/probesemver/

## Install / run

```bash
git clone https://github.com/theworker02/probesemver.git
cd probesemver
node src/cli.js
node --test
```
